# 🇦🇷 Análisis de Distribución de EE y BP en Argentina

**Materia:** Laboratorio de Datos (FCEyN - Universidad de Buenos Aires)  
**Integrantes:** Maite Alice, Abril Echarri y Facundo Miguel.

## 📌 Descripción del Proyecto
Este repositorio contiene el trabajo práctico final de la materia, cuyo objetivo es investigar si existe algún patrón o relación entre la cantidad de Establecimientos Educativos (EE) y la de Bibliotecas Populares (BP) en las diferentes provincias y departamentos de Argentina, utilizando datos oficiales del Censo 2022.

## 🗂️ Estructura del Repositorio
* `data/raw/`: Datasets originales (Censo 2022, Padrones oficiales).
* `data/processed/`: Tablas limpias y normalizadas tras la aplicación del modelo relacional.
* `notebooks/`: Código fuente en Jupyter Notebook interactivo (`analisis_tp.ipynb`).
* `docs/`: Informe final del trabajo práctico en formato PDF.

## 🛠️ Tecnologías Utilizadas
* **Python** (Pandas) para manipulación y limpieza de datos.
* **DuckDB** para consultas SQL eficientes.
* **Matplotlib** para visualización de datos.

## 🚀 Metodología Aplicada
1. Revisión de calidad de datos usando métricas **GQM (Goal-Question-Metric)**.
2. Diseño de Diagrama Entidad-Relación (DER) en Tercera Forma Normal (3FN).
3. Transformación de datos y cruce de tablas.
4. Análisis exploratorio y visualización.
